O bot abaixo nasceu só como teste de criação de bot para o Telegram. Dá para transformá-lo em algo realmente útil sem muito esforço: bastaria responder o telefone da empresa, o endereço da loja ou a lista de produtos.

Rodei tudo na máquina local, com o comando do Node, mas nada impede subir para um servidor.

Enquanto esse processo não estiver ativo, o bot simplesmente não responde às partidas de Jankenpo.

Detalhe: o token exigido pelo Telegram é lido de uma variável de ambiente chamada TOKEN_JANKENPO_TELEGRAM.

Gravação da demonstração e o post que publiquei na rede profissional ficam nos links de sempre.

> [!IMPORTANT]
> Repare que a saida pode variar conforme a versao do runtime.
